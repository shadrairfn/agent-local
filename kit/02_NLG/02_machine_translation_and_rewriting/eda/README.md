# 🎯 Task-Specific EDA: Machine Translation & Text Rewriting

## Overview
This diagnostic notebook assesses parallel corpora for machine translation, style transfer, and prompt recovery.

## Key Diagnostic Outputs
1. **Word Fertility Ratio:** Ratio between target sentence length and source sentence length.
2. **Length Correlation:** Verifies strict alignment between source and target text.
3. **Cross-Lingual Vocabulary Overlap:** Identifies named entities, acronyms, and loanwords preserved across language pairs.
