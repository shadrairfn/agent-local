# 🎯 Task-Specific EDA: Named Entity Recognition & Token Classification

## Overview
This diagnostic notebook analyzes sequence labeling datasets formatted under the BIO (Beginning, Inside, Outside) tagging scheme.

## Key Diagnostic Outputs
1. **Token Imbalance Ratio:** Quantifies the ratio between uninformative background tokens (`O`) and target entities.
2. **Entity Class Balance:** Detects rare entity classes requiring focused sampling or weighted loss.
3. **BIO Transition Validity:** Verifies syntactic grammar of entity spans.
